## Weeks 1-4: Foundation

### Mon: Push
- Push-ups | 4x10 | rest 90s | note: elbows at 45 degrees, full lockout
- Pike push-ups | 3x8 | rest 90s
- Bench dips | 3x10 | rest 60s
- Plank | 3x40s | rest 45s

### Tue: Pull
- Australian rows | 4x10 | rest 90s | note: squeeze shoulder blades at the top
- Negative pull-ups | 3x5 | rest 120s | note: 4-second lowering
- Dead hang | 3x30s | rest 60s
- Superman hold | 3x20s | rest 45s

### Thu: Legs + Core
- Squats | 4x15 | rest 60s
- Reverse lunges | 3x10 each leg | rest 60s
- Glute bridges | 3x15 | rest 45s
- Hollow hold | 3x20s | rest 45s | note: lower back pressed flat

### Sat: Full Body
- Push-ups | 3x12 | rest 60s
- Australian rows | 3x12 | rest 60s
- Jump squats | 3x10 | rest 60s
- Mountain climbers | 3x30s | rest 45s

## Weeks 5-8: Build

### Mon: Push
- Diamond push-ups | 4x8 | rest 90s
- Decline pike push-ups | 4x6 | rest 120s
- Parallel bar dips | 3x6 | rest 120s
- Plank shoulder taps | 3x20 | rest 45s

### Tue: Pull
- Pull-ups | 5x3 | rest 150s | note: add a rep per set when all sets feel clean
- Chin-ups | 3x4 | rest 120s
- Australian rows | 3x12 | rest 60s
- Hanging knee raises | 3x10 | rest 60s

### Thu: Legs + Core
- Bulgarian split squats | 4x8 each leg | rest 90s
- Step-ups | 3x10 each leg | rest 60s
- Single-leg glute bridges | 3x10 each leg | rest 45s
- Hollow body rocks | 3x15 | rest 45s

### Sat: Full Body
- Archer push-ups | 3x5 each side | rest 90s
- Pull-ups | 3x4 | rest 120s
- Jump lunges | 3x8 each leg | rest 60s
- L-sit tuck hold | 4x10s | rest 60s

## Weeks 9-12: Strength

### Mon: Push
- Pseudo planche push-ups | 4x6 | rest 120s | note: lean forward until wrists feel it
- Pike push-ups on box | 4x8 | rest 120s
- Parallel bar dips | 4x8 | rest 120s
- Hollow hold | 3x40s | rest 45s

### Tue: Pull
- Pull-ups | 5x6 | rest 150s
- Chin-ups | 4x6 | rest 120s
- Archer rows | 3x6 each side | rest 90s
- Hanging leg raises | 3x8 | rest 60s

### Thu: Legs + Core
- Shrimp squat progression | 4x5 each leg | rest 120s
- Bulgarian split squats | 3x10 each leg | rest 90s
- Nordic curl negatives | 3x4 | rest 120s | note: lower as slowly as you can
- Dragon flag negatives | 3x4 | rest 90s

### Sat: Test Day
- Max push-ups | 1xmax | note: log the number and beat it next week
- Max pull-ups | 1xmax
- Max squats | 1xmax
- Max plank | 1xmax
